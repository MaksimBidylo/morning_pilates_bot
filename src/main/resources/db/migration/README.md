SQL-миграции приложения размещаются в этой папке.

Первая продуктовая миграция будет называться, например, `V1__create_techniques.sql`.
Flyway запускается при старте приложения до Telegram polling и хранит историю
в таблице `flyway_schema_history`. Уже применённые миграции менять нельзя:
для изменения схемы добавляйте следующий файл `V2__...sql`.

Продуктовых таблиц пока нет. Тестовые миграции находятся отдельно,
в `src/test/resources/db/test-migration`, и не входят в образ приложения.
