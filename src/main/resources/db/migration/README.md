SQL-миграции приложения размещаются в этой папке.

- `V1`: пользователи, тренировки и техники.
- `V2`: флаг администратора пользователя.
- `V3`: время создания сохранённой тренировки.
- `V4`: необязательные поля личного профиля спортсмена, одна строка на пользователя.
- `V5`: даны 0–10 для чёрного пояса; для остальных поясов полоски остаются 0–4.

Flyway запускается до Telegram polling и хранит историю в `flyway_schema_history`.
Уже применённые миграции менять нельзя: для изменения схемы добавляйте следующий файл.
Тестовые миграции находятся отдельно в `src/test/resources` и не входят в образ приложения.
