# Morning Pilates Bot

Персональный Telegram-дневник тренировок по Brazilian Jiu-Jitsu (BJJ).
Записывайте дату, время, изученные техники и заметки, возвращайтесь к своим
тренировкам и удаляйте ошибочные записи прямо в личном чате с ботом.

## Возможности MVP

- Пошаговая запись тренировки с подтверждением сохранения. Техники, их описания
  и заметка необязательны; можно сохранить тренировку без техник.
- Просмотр последней тренировки и всех тренировок за выбранную дату.
  Карточки за день перелистываются в одном сообщении.
- Удаление конкретной записи из карточки просмотра с отдельным подтверждением.
- Отмена текущего действия и аварийный сброс незавершённых действий.

## Команды

Команды дневника используются **в личном чате**. Каждый пользователь работает
со своими записями.

| Команда | Назначение |
|---|---|
| `/start` | Приветствие и краткое описание бота |
| `/help` | Встроенная справка |
| `/training_add` | Записать тренировку |
| `/training_get_last` | Показать последнюю тренировку по дате и времени проведения |
| `/training_get_date` | Найти все свои тренировки за дату |
| `/cancel` | Закрыть просмотр; если его нет — отменить создание тренировки |
| `/cancel_all` | Сбросить все незавершённые действия текущего пользователя |

Отдельной команды `/delete` нет: кнопка **«Удалить тренировку»** находится
в карточках просмотра. После первоначального сохранения карточка приходит без неё.

## Пример использования

Отправьте `/training_add`, введите дату, например `15.10.2026`, и время `19:00`.
Добавьте техники и заметку либо пропустите их кнопкой «Нет». На вопрос
«Сохранить тренировку?» нажмите «Да».

Бот покажет «Тренировка сохранена.» и карточку со свёрнутой цитатой.
Для чтения отправьте `/training_get_last` или `/training_get_date`.
Для удаления откройте нужную карточку, нажмите «Удалить тренировку», проверьте
дату и время, затем подтвердите «Да, удалить». **Восстановления удалённой записи нет.**

Повторный `/training_add` не стирает черновик: бот присылает новый видимый вопрос
текущего шага. Если диалог запутался, `/cancel_all` сбросит незавершённые действия,
но не удалит сохранённые тренировки.

## Ограничения

Незавершённые действия хранятся в памяти и теряются при перезапуске приложения.
Сохранённые тренировки находятся в PostgreSQL. Поиск по дате листает загруженный
снимок списка; новый поиск обновляет его из БД.

Очистка чата и доставка результата зависят от Telegram. Успешное сохранение или
удаление в БД не откатывается из-за ошибки отображения. `/cancel_all` не гарантирует
отмену уже начатого сохранения. Если сообщение не обновилось, используйте команды
просмотра или отмены; старые кнопки не восстанавливают завершённое действие.

Нет редактирования сохранённой тренировки, корзины, экспорта, поиска по техникам,
статистики, платежей и автоматических напоминаний. Подробности — в
[ограничениях пользовательских сценариев](docs/user-flows.md#ограничения).

## Быстрый локальный запуск

Нужны Docker с Compose, Python 3, OpenSSL и отдельный тестовый токен от BotFather.
JDK на компьютере для контейнерного запуска не требуется. Команды выполняются
из корня репозитория.

```sh
./scripts/setup_compose.py --up
curl --fail http://127.0.0.1:8080/health
docker compose logs -f app
```

Скрипт создаёт недостающие ключи в `.env`, при необходимости запрашивает токен
скрытым вводом и сохраняет его в локальном конфиге. Уже существующие настройки
не перезаписываются. Не добавляйте эти файлы в Git.

`/health` возвращает `OK`, но проверяет только HTTP-сервер, не БД и не Telegram.
Для проверки самого бота отправьте `/start`, затем создайте и просмотрите тестовую
тренировку. Остановить контейнеры с сохранением volume БД:

```sh
docker compose down
```

Настройка портов, запуск из IDE, отладка и тесты — в
[руководстве по разработке](docs/development.md).
