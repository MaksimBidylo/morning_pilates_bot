# Morning Pilates Bot

Проект Telegram-бота для BJJ-группы. Цель — сохранять и находить информацию
об изученных техниках, а также получать цитаты тренера по запросу.

Планируется, что администратор будет добавлять описания техник,
а участники — возвращаться к материалам тренировок через чат группы.

## Возможности

Предусмотренный MVP:

- Администратор добавляет описание техники в личном чате с ботом.
- Участники группы запрашивают сохранённые техники в групповом чате.
- Участник группы запрашивает цитату тренера, бот отправляет её в чат.

## Статус разработки

Реализовано:

- Бот подключается к Telegram и отвечает на команду `/start`.
- Сценарий создания тренировки: ввод даты, времени, техник, описаний и заметки,
  подтверждение и отмена. Логика проверена модульными и интеграционными тестами.
- Локальный запуск через Docker Compose и HTTP-проверка `/health`.

Пока недоступно:

- Создание тренировки через Telegram: сценарий ещё не подключён к боту.
- Постоянное сохранение тренировок в PostgreSQL: в тестах используется
  `FakeTrainingRepository`, реализации репозитория для БД пока нет.
- Поиск сохранённых техник, выдача цитат тренера и проверка ролей.

## Технологии

- Kotlin / JDK 25.
- Ktor.
- Telegram Bot API.
- PostgreSQL.
- jOOQ.
- Flyway.
- Gradle с Kotlin DSL.

Тесты: JUnit, ArchUnit и Testcontainers.
Версии зависимостей и плагинов определены в
[gradle/libs.versions.toml](gradle/libs.versions.toml), версия Gradle — в
[gradle-wrapper.properties](gradle/wrapper/gradle-wrapper.properties).

## Быстрый запуск

Нужен Docker с поддержкой Compose и токен бота от BotFather.
JDK и Gradle на компьютере для этого способа не требуются.
Все команды выполняются из корня репозитория.

1. Создайте локальный файл конфигурации:

   ```sh
   touch src/main/resources/application-local.conf
   ```

2. Запишите в него токен своего бота:

   ```hocon
   telegram {
       botToken = "YOUR_TELEGRAM_BOT_TOKEN"
   }
   ```

   Параметры локальной БД уже заданы в [compose.yaml](compose.yaml).
   Локальный конфиг исключён из Git и Docker-образа.

3. Соберите образ и запустите приложение с PostgreSQL:

   ```sh
   docker compose up --build -d
   ```

4. Проверьте HTTP-сервер:

   ```sh
   curl http://127.0.0.1:8080/health
   ```

   Ожидаемый ответ — `OK`. Отправьте своему боту `/start`:
   он должен ответить «Morning Pilates Bot работает 🥋».

Остановить приложение и PostgreSQL:

```sh
docker compose down
```

Настройка портов, просмотр логов, работа с БД и дополнительные способы запуска —
в [руководстве по разработке](docs/development.md).
