# Morning Pilates Bot

Morning Pilates Bot — персональный Telegram-дневник тренировок по Brazilian Jiu-Jitsu (BJJ).
Каждый пользователь ведёт собственный дневник тренировок и изученных техник.

## Возможности

Личный дневник включает:

- Дату и время тренировки.
- Изученные техники с необязательными описаниями.
- Необязательную заметку о тренировке.

## Статус разработки

Реализовано:

- Бот подключается к Telegram и отвечает на команду `/start`.
- `/training_add` в личном чате создаёт сессию и запрашивает дату тренировки.
  Повторная команда сохраняет незавершённую сессию.
- Ввод даты через Telegram: проверка, сообщение об ошибке или переход к запросу времени.
- Training Flow с подтверждением и отменой.
- Валидация пользовательского ввода, включая строгую проверку даты и времени.
- PostgreSQL-репозитории пользователей и тренировок с защитой Telegram ID.
- Атомарное и идемпотентное сохранение тренировок вместе с техниками.
- Модульные и интеграционные тесты.
- Локальный запуск через Docker Compose и HTTP-проверка `/health`.

Пока недоступно в Telegram:

- Дальнейшие шаги создания тренировки: ввод времени, техник и заметки,
  inline-кнопки «Да/Нет», подтверждение и сохранение в PostgreSQL через Telegram.
- Просмотр истории собственных тренировок — планируется.

## Технологии

- Kotlin / JDK 25.
- Ktor.
- Telegram Bot API.
- PostgreSQL.
- jOOQ.
- Flyway.
- Gradle с Kotlin DSL.

Тесты: JUnit, ArchUnit и Testcontainers.
Версии зависимостей и плагинов определены в
[gradle/libs.versions.toml](gradle/libs.versions.toml), версия Gradle — в
[gradle-wrapper.properties](gradle/wrapper/gradle-wrapper.properties).

## Быстрый запуск

Нужны Docker с поддержкой Compose, Python 3, OpenSSL и токен бота от BotFather.
JDK и Gradle на компьютере для этого способа не требуются.
Все команды выполняются из корня репозитория.

1. Настройте окружение и запустите приложение с PostgreSQL:

   ```sh
   ./scripts/setup_compose.py --up
   ```

   Скрипт создаст ключи в `.env`, при необходимости запросит токен бота скрытым вводом
   и сохранит его в локальном конфиге. Затем проверит Compose и запустит контейнеры.
   При повторном запуске существующие ключи и настройки сохраняются.

2. Проверьте HTTP-сервер:

   ```sh
   curl http://127.0.0.1:8080/health
   ```

   Ожидаемый ответ — `OK`. Отправьте своему боту `/start`:
   он должен отправить приветствие «Morning Pilates Bot 🥋» с описанием дневника BJJ
   и командами `/training_add — записать тренировку`,
   `/training_get_last — посмотреть последнюю тренировку` и `/help — помощь`.

Остановить приложение и PostgreSQL:

```sh
docker compose down
```

Подробная настройка окружения, портов, просмотр логов и дополнительные способы запуска —
в [руководстве по разработке](docs/development.md).
